# Parked monetization prototype

Status: inactive, unreachable, and excluded from Dialed's build and package.

These files preserve an early UI and local-entitlement experiment for historical
reference only. They are not product behavior, release evidence, or an approved
architecture. The prototype has no usable activation codes and no configured
checkout provider. Dialed continues to expose the full implemented feature set in
the normal local profile while monetization is deferred.

Do not import these files back into `src`. Reactivation requires a new explicit
product decision, a threat model for entitlement and payment boundaries, a real
provider contract, abuse-resistant server-side validation, privacy and legal
review, and tests proving that the owner's access cannot be reduced.
