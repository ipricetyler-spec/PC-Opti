# External visual reference evidence

Private reference screenshots and research notes were moved out of the active
repository on 2026-08-30. They remain preserved under the private E: reference
archive and are not product assets, test fixtures, implementation inputs, or
release material.

The active repository records only the resulting independent product decisions:

- keep games, network, input devices, and measurement in separate workspaces;
- prefer search, filters, bounded actions, explicit previews, and visible undo;
- reject broad debloat, universal latency claims, security weakening, hidden
  mutations, or copied wording, layouts, assets, recipes, and implementation;
- verify Dialed behavior from its own source, fixtures, package contents, and
  owner acceptance evidence.

No external application installation or private reference archive is needed to
build, test, package, or use Dialed.
